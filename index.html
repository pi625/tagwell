Why this matters now

Deadlines

ADA Title II: 26 April 2027 for governments serving 50,000+ people, 26 April 2028 for smaller ones. HHS Section 504: 11 May 2027. The European Accessibility Act is already enforced.

Fixed files still need checking

AI remediation now costs under a dollar a page, but the usual checkers only test what a machine can test. Someone still has to open every page.

Tagwell does that check

It reads each page the way a screen reader would and shows you exactly which pages need a person, and why.

What it checks

ProblemReference
Reading order doesn't match the layout (columns read across, blocks out of place)Matterhorn 09-001, WCAG 1.3.2
Big bold text tagged as a paragraph instead of a headingMatterhorn 14-001
Table header rows or columns tagged as data cells; tables tagged as plain textMatterhorn 15-001/15-002, 09-003
Bulleted or numbered text not tagged as a listMatterhorn 16-003
Running headers and page numbers read on every page; body text hidden as decorationMatterhorn 01-001/01-002
Form fields named "Text1", unnamed, or announced differently from their printed label; fields visited out of orderMatterhorn 28-005/28-001, WCAG 2.5.3, 4.1.2
Alt text that is a file name or a generic word; titles like "Microsoft Word - final.docx"; wrong declared languageWCAG 1.1.1, 2.4.2, 3.1.1
Plus the machine checks: untagged content, missing title/language, table/list syntax, encryption that blocks assistive technologyMatterhorn 01, 06, 07, 09, 11, 13, 14, 15, 26, 28
